# Reference Library

This section is for looking things up.

You do not need to follow these pages in order.

If you encounter an unfamiliar Sims 4 tuning resource, system, XML term, or modding concept, use the reference library to find an explanation.

---

## Reference Sections

### [Tuning Types](tuning-types/README.md)

Detailed explanations of Sims 4 tuning types, including:

- what they are
- what they do
- where you encounter them
- how they connect to other tuning
- common XML concepts
- common modding uses
- frequently asked questions

More reference sections may be added as the repository grows.

---

# Course vs Reference Library

Use the **course** when you want to learn concepts in a structured order.

Use the **reference library** when you have a specific question.

```text
"I want to learn Sims 4 modding."
              |
              v
            Course

"I found this tuning.
What does it do?"
              |
              v
      Reference Library
```

Both sections are designed to work together.

---

# Reference Philosophy

This reference library is designed to give both **quick** explanations + **in-depth** explanations, determined by how far you're willing to read. Whether you're in a rush or in the mood to study, you should still be able to walk away with the knowledge you were looking for. 

Here's how the reference pages will be structured:

```text
Quick explanation
        |
        v
Mental model
        |
        v
Common uses
        |
        v
Connections
        |
        v
XML / technical details
        |
        v
Advanced information
```

Read as much or as little as you need.
